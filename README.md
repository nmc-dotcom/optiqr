# optiqr
브라우저에서만 동작하는 QR 디자이너. 스캔 품질 검사 내장

## Phase 1 완료 기준

미검증 항목은 로컬에서 확인 필요.

- [x] 8종 데이터 타입 각각에서 실제 기기 스캔 성공 (URL·텍스트·이메일·전화·SMS·WiFi·명함·위치)
- [x] 입력·디자인 변경 시 재생성 버튼 없이 미리보기 즉시 갱신
- [ ] Dot 6종 × Eye 4종 조합에서 QR이 깨지지 않고, 로고 20% + ECC H 조합이 스캔됨
- [x] PNG·SVG 다운로드 동작, SVG를 브라우저에서 열었을 때 미리보기와 동일
- [x] 품질 검사가 명암비·로고·Quiet Zone·Eye 대비·ECC·모듈 해상도·데이터 과다를 실시간 판정
- [x] 의도적으로 나쁜 설정을 만들면 오류 등급이 뜨고 실제로도 스캔 실패
- [ ] **로고 크기를 5%→40%로 올리며, 검사기가 오류로 바뀌는 지점과 실제 스캔이 깨지는 지점이 일치**
- [ ] 프리셋 저장 → 기본값 복귀 → 다시 불러오기 시 디자인 복원, 파일에 입력 데이터 없음
- [ ] 망가뜨린 프리셋 파일(범위 초과·타입 오류·원격 이미지 URL)을 불러와도 앱이 죽지 않음
- [ ] 네트워크 탭에 외부 요청 0건
- [ ] 모바일 폭 375px에서 레이아웃 유지

7번째 항목이 이 도구의 차별화 주장이 성립하는지를 결정함. 이게 맞아떨어지지 않으면 품질 검사는 장식임.
